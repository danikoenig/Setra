# SETRA

Set Builder for DJs. Build the order of your evening from a Rekordbox playlist.

Open the web version: https://danikoenig.github.io/Setra/

## What it does

- Reads an M3U8 playlist exported from Rekordbox and picks up BPM, key and energy from the file tags (for example from Mixed In Key). Where energy is missing it estimates it from the audio. Every value stays editable.
- Suggests a set order from the shape you choose (gentle build-up, slow burn, break, waves and more), taking energy, key and BPM into account.
- Lets you reorder by drag and drop and listen in with master tempo.
- Exports a new M3U8 that you import back into Rekordbox. Your cues stay untouched.

## How to use it

1. In Rekordbox, export your playlist as .m3u8.
2. Open the page, choose the playlist and choose your Rekordbox Contents folder so the tracks can be played.
3. Pick a mood, press "Suggest set", adjust, then save the playlist and import it in Rekordbox.

Everything runs in your browser. No file is uploaded anywhere.

A native Mac app is in the works.
